# Contributing to rag_control

Thank you for your interest in contributing to rag_control! We welcome community involvement and appreciate your support.

## Issues

**Anyone can open an issue.** If you've found a bug, have a feature request, or want to discuss something about the project, please feel free to:

1. Check existing issues to avoid duplicates
2. Open a new issue with a clear title and description
3. Include relevant details (error messages, steps to reproduce, environment info, etc.)
4. Use appropriate labels if available

## Pull Requests

**Anyone can submit a pull request!** We welcome contributions from the community. To ensure quality and maintainability:

1. **Before You Start**: Open an issue first to discuss your proposed changes
2. **Follow Quality Standards**:
   - All tests must pass: `make test`
   - 100% code coverage required: `make coverage`
   - Type checking: `make typecheck`
   - Linting: `make lint`
   - Formatting: `make format`
3. **PR Guidelines**:
   - Use descriptive branch names (e.g., `feat/add-feature`, `fix/issue-123`)
   - Keep commits atomic and well-described
   - Reference related issues in PR description
   - Write clear PR descriptions explaining your changes

## Getting Involved

If you're interested in joining the RetrievalLabs team or becoming a regular contributor, please reach out to the team through:
- GitHub discussions
- Email contact through RetrievalLabs Co.

## Code of Conduct

- Be respectful and constructive
- Focus on the issue or idea, not personal criticism
- Help others learn and grow
